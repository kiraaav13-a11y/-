# MIMI ✦

A cute Russian-language interactive prototype for analyzing everyday situations.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. Save. The site will be published at https://kiraaav13-a11y.github.io/-/

## Important: current prototype limitations
This is a front-end demo, not a connected AI fortune teller. The current analysis uses simple demo rules; it does not truly understand uploaded screenshots or images. Saved history exists only in the current browser tab and is not synced.

For real analysis of text, conversations, and screenshots, connect a model through a secure backend. Never put a secret AI API key in public HTML or JavaScript. Avoid uploading passwords, addresses, or other sensitive personal information.
